SETUP FLOW:
═══════════════════════════════════════════════════════════════

1. Create directory structure:
   mkdir -p terraform-vm-testing/{terraform,.github/workflows,.ssh,.docs}

2. Place Terraform files in terraform/:
   - main.tf
   - variables.tf
   - resources.tf
   - outputs.tf

3. Place workflow in .github/workflows/:
   - vm-provision-workflow.yml

4. Generate SSH key in .ssh/:
   ssh-keygen -t rsa -b 4096 -f .ssh/id_rsa -N ""

5. Create .gitignore and README.md in root

6. Initialize git and commit:
   cd terraform-vm-testing
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin <your-github-repo>
   git push -u origin main
